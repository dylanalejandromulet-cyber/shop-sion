# Shop Sion – Technology & Accessories

Sitio web estático listo para publicar con GitHub Pages.

## Publicación
1. Sube `index.html` a la raíz del repositorio de GitHub.
2. En el repositorio, abre **Settings → Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**.
4. Selecciona la rama `main` y la carpeta `/ (root)`, y pulsa **Save**.
5. Espera a que GitHub Pages publique el sitio.

## Nota sobre el catálogo y el administrador
Esta versión guarda el catálogo y el acceso de administrador en el almacenamiento local del navegador/dispositivo. No sincroniza automáticamente productos entre distintos teléfonos o navegadores. Para que los clientes vean los mismos productos desde cualquier dispositivo se necesita una base de datos o un mecanismo de publicación/sincronización.
